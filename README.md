# Generative AI & Prompt Engineering for Developers · Webinar

**Website:** https://gradlabs.in/learn/genai-webinar/ (unlisted: shared by link, not on the home page or in search engines)

Companion notebook for the live webinar for students and junior developers:
how LLMs work, six prompt techniques with before-and-after activities, and a demo you can run in Colab.

- `index.html` — webinar home: event details, resources, parts of the talk, keep learning
- `lessons/talk.html` — the talk, one part per screen
- `assets/course.js` — webinar settings (date, speaker, resource links)
- `assets/talk.js`, `assets/talk.css` — this webinar's activities
- `notebooks/genai_webinar_demo.ipynb` — the live demo, works with Gemini (free), Claude or OpenAI

[Open the demo in Colab](https://colab.research.google.com/github/mo-ri-ch/genai-webinar/blob/main/notebooks/genai_webinar_demo.ipynb)
